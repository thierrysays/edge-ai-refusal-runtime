# ADR 0001, Record architecture decisions

**Status:** accepted · 2026-08-21

## Context

A governance repository whose own decisions are undocumented is an argument
against itself. The interesting content of this project is not the code but the
choices, most of which have a cost that a reader is entitled to weigh.

## Decision

Every choice that a competent engineer could reasonably have made differently is
recorded here, with its cost stated. ADRs are immutable: a reversal is a new ADR
that supersedes the old one, never an edit.

## Consequences

The uncomfortable ADRs (0006, 0007) are the ones worth reading. A decision log
containing only flattering decisions is marketing.
